# 業務の説明から FlowCanvas の図を作る

FlowCanvas（`flowcanvas/`）には、決まった形の表を図にするコマンドがある。
ユーザーの資料をその形の表（CSV）に整えてから、コマンドで取り込む。

## 表の形

1行に1つの作業。列は次のとおり（見出しはこの名前のまま）。

| 列 | 書くこと |
|---|---|
| No | 作業の番号（必須・重ならない） |
| 誰が | 作業をする人・部署・システム（必須） |
| 何をする | 作業の名前（必須）。短く「〜する」で |
| 形 | 作業（空なら作業）・判断・開始・終了・メール・書類・人・時計・付せん・データ・Excel・CSV・PC |
| 誰・何に対して | 相手。システムなら「受け渡すもの」がデータとして点線でつながる |
| 受け渡すもの | やり取りするデータや書類 |
| 向き | 相手がシステムのとき：渡す（登録）／受け取る（参照）。空なら渡す |
| 次のNo | 次の作業の No。分岐は「4, 5」。空なら次の行。終わりなら「なし」 |
| 条件 | 分岐の条件。次のNo と同じ順に「承認, 差し戻し」 |
| メモ | 補足。分からないことは「要確認：〜」と書く |

枠（担当者・システム）は別の CSV に `名前,区分,説明`（区分は「担当者」か「システム」）で書く。出したい順に並べる。

記入例は `flowcanvas/templates/業務フロー_取り込みひな形.xlsx`（中身は `npm run dump -- templates/業務フロー_取り込みひな形.xlsx` で見られる）。

## 手順

1. **資料を読む**
   - Excel：`cd flowcanvas && npm run dump -- <ファイル>` で中身を表示して読む
   - CSV・テキスト・議事録：そのまま読む
   - すでに上の表の形なら、手順 3 へ進んでそのまま取り込んでよい
2. **表に整える**
   - 資料に書いてあることだけを使う。作業・担当者・システム・条件を推測で足さない
   - 分からない所は作業を作らずに済ませるか、メモに「要確認：〜」と書き、最後にユーザーへ伝える
   - 承認・確認で結果が分かれる所は「判断」にして、次のNo と条件を書く
   - 差し戻しなど前に戻る流れは、次のNo に前の No を書く（図では上を回る線になる）
   - システムの名前は資料の書き方にそろえる（同じシステムを別の名前で書かない）
   - `flowcanvas/imports/<名前>.csv` と `flowcanvas/imports/<名前>_枠.csv` に UTF-8 で保存する（`imports/` は Git に入らない）
3. **ユーザーに確認する**
   - 担当者・システム・作業の数と、判断・要確認の箇所を短く見せ、取り込んでよいか聞く
4. **取り込む**
   ```
   cd flowcanvas
   npm run import -- imports/<名前>.csv --lanes imports/<名前>_枠.csv --title "<図のタイトル>"
   ```
   - エラーが出たら、行番号を見て CSV を直してもう一度実行する
   - （注意）が出たら、その内容をユーザーに伝える
5. **伝える**
   - ブラウザで http://localhost:5173 を開き（開いていれば再読み込みして）、上の「図：」から選ぶよう案内する
   - アプリが起動していなくても図は `flowcanvas/data/` に保存され、次に `npm run dev` で起動したときに出る

## 守ること

- 資料の内容をこの PC の外へ送らない（Web 検索や外部のサービスに貼らない）
- 既存の図は書き換えない（取り込みは常に新しい図を作る）
