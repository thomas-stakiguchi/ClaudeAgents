# FlowCanvas

業務フローとデータフローを1枚に描けるエディタです。ローカルPCで動かします。

## 起動のしかた

Node.js 18 以上が必要です。

```bash
cd flowcanvas
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。初回はサンプル（受注〜請求）が1件入っています。

- 図は `flowcanvas/data/` に1図1ファイル（JSON）で自動保存されます
- 止めるときはターミナルで Ctrl+C

ビルドして1プロセスで動かす場合：

```bash
npm run build
npm start   # http://localhost:3001
```

## ファイル版を作って配る

Node.js を入れていない人には、1つの HTML ファイルにまとめたものを配れます。

```bash
npm run build:file   # release/FlowCanvas.html ができる（約2MB）
```

1. `release/FlowCanvas.html` を Google ドライブや Box で、渡したい人だけに共有する
2. 受け取った人はダウンロードして、ダブルクリックで開く（Chrome か Edge をおすすめ）

ファイル版の違い：

- 図は**その人のブラウザの中**に保存される（サーバーは使わない）。ブラウザのデータを消すと図も消えるので、「保存」の後の「ファイルにも保存」で控えを残してもらう
- 控えのファイルは「読み込み」→「JSON」で戻せる。PC を替えたときもこれで移せる
- 新しい版を配ったら、同じ PC・同じブラウザで開けば図はそのまま残っている
- 丸ゴシックの文字はネットから読み込む。つながっていないときは PC の文字で表示される
- `npm run dev` の版とは保存先が別なので、図は共有されない（移すときは JSON で）

## 使い方

画面は2つに分かれています。

- **左のパネル**：図の中身を作る（1 枠を作る → 2 部品を置く → 3 線でつなぐ・文章でつなぐ）。見出しをクリックすると開いたり閉じたりできる
- **上のバー**：図そのものの操作（図の切替・新しい図・取り消し・拡大縮小・読み込み・書き出し・保存）。図の複製・削除・サンプル・画面の明るさは右端の「…」
- **操作の説明**：上の「？ 操作ガイド」にまとめてある

| やりたいこと | 操作 |
|---|---|
| 担当・システムの枠を増やす | 左「1 枠を作る」の「＋ 追加」 |
| 部品を置く | 左「2 部品を置く」の部品をキャンバスへドラッグすると、その場所に置ける。クリックすると選んでいる枠の右端に置く（置く先はパレットの下に出る） |
| アイコンの部品 | 「2 部品を置く」の「アイコン」を開く：Excel・CSV・PC・メール・書類・人・時計（付せんは「基本」） |
| 矢印でつなぐ | 部品にマウスを乗せて出る丸をクリック → 相手の部品をクリック |
| 文章でつなぐ | 左「文章でつなぐ」を開いて「作業とデータを点線で繋ぐ。線は赤。」のように書いて Enter |
| 線の色を変える | 線をクリック → 右のパネルの「線の色」から選ぶ（Excel と同じ並び） |
| 長い名前 | 作業・判断・データ・付せんは、名前の長さに合わせて横に広がり、収まらなければ縦に伸びる |
| 名前を変える | 部品をダブルクリック（または選んで Enter）→ 部品の上でそのまま打って Enter。Shift+Enter で改行、Esc で取り消し |
| まとめて選ぶ | Shift+クリックで足す／Shift+背景ドラッグで範囲を囲む／Ctrl+A で全部 |
| まとめて動かす・消す | 選んだ部品のどれかをドラッグ／Delete |
| コピー・貼り付け | Ctrl+C → Ctrl+V。別の図にも貼れる（同じ名前の枠に入る） |
| そろえる | 2つ以上選ぶと右のパネルに「左端・中心・右端・枠の上下中央・横に等間隔」が出る |
| 直角の線 | 左「3 線でつなぐ」で「直角（カギ線）」を選んでからつなぐ。あとから右のパネルでも変えられる |
| 線の重なりを直す | 同じ辺に付く線は自動で少しずつずらす。曲線や直角の線が途中の部品にぶつかるときは、自動で回り込む。それでも重なるときは、線を選んで右のパネルの「出る辺・入る辺」を変える |
| 消す | 選んで Delete |
| 保存する | 上の「保存」または Ctrl+S（編集から0.5秒で自動保存もされる）。押すと「ファイルにも保存」をすすめる小窓が出る（「…」メニューで出さないようにもできる） |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Shift+Z |
| 書き出す | 上の「書き出し ▾」から PNG / JPG / PDF / テキスト |
| 書き出しの設定 | 「書き出し ▾」の下の方で選ぶ：「タイトル・出力日・凡例を入れる」「白い背景・マス目なし（印刷向け）」（どちらも最初は入） |
| 枠の高さ | 枠の見出しにマウスを乗せて「広く／狭く」、または枠の下の境目をドラッグ。右のパネルでも変えられる |
| 全体を見る | 図を開いたときは読める大きさ（70%〜100%）で出る。全体を見たいときは上の倍率（「70%」など）を押す（10%まで縮む）。横に動かしても枠の名前は左端に残る |
| 明るさを変える | 右上の「…」→ 画面の明るさ：自動 / ライト / ダーク |

### 文章でつなぐときの書き方

- 部品の名前を2つ書く：「見積を作成すると商談を繋ぐ」
- 向き：「AからBへ」と書くとその向き。書かなければ先に書いた方が元
- 線：「点線」「実線」、形：「直角」「曲線」
- 色：赤・青・緑・黄・オレンジ・紫・黒・灰色・水色・黄緑・紺・ピンク・茶、または #FF0000 のような色番号
- ラベル：「ラベルは〇〇」または「〇〇」
- 部品が1つしかない種類なら、名前の代わりに「作業」「データ」「判断」「開始」「終了」「Excel」「CSV」「PC」「メール」「書類」「顧客」「時計」「付せん」でも通じる
- 名前を書かずに「赤にする」だけ書くと、選んでいる線の色が変わる
- すでにつながっている2つを書くと、新しく作らずにその線を変える

決まった言葉を探して読み取る方式です（AI は使っていません）。読み取れないときは、理由が欄の下に出ます。

## Excel・CSV から図を作る

「誰が・誰（何）に対して・何をする」を1行ずつ書いた表から、図を自動で作れます。

**画面から**

1. 上の「読み込み（Excel・JSON）」→「Excel・CSV から作る」
2. 「ひな形をダウンロード」で記入例と「書き方」シート付きの Excel を取り、「業務の流れ」シートに作業を書く（「枠」シートには担当者とシステムを出したい順に。なくても動く）
3. 「ファイルを選ぶ」で書いた Excel（または CSV）を選ぶ → 件数と注意を確かめて「図を作る」

**コマンドで**

1. ひな形を作る：`npm run template`（`templates/業務フロー_取り込みひな形.xlsx` ができる）
2. 取り込む：`npm run import -- 業務一覧.xlsx`（`--title "タイトル"` で図の名前を指定。CSV も読める。枠を別の CSV にするときは `--lanes 枠.csv`）
3. ブラウザを再読み込みして、上の「図」から選ぶ

| 列 | 書くこと |
|---|---|
| No | 作業の番号（必須） |
| 誰が | 作業をする人・部署・システム（必須） |
| 何をする | 作業の名前（必須） |
| 形 | 作業（空なら作業）・判断・開始・終了・メール・書類・人・時計・付せん・データ・Excel・CSV・PC |
| 誰・何に対して | 相手。システムなら「受け渡すもの」をデータとして点線でつなぐ |
| 受け渡すもの | やり取りするデータや書類 |
| 向き | 相手がシステムのとき：渡す／受け取る |
| 次のNo | 次の作業。分岐は「4, 5」。空なら次の行。終わりなら「なし」 |
| 条件 | 分岐の条件（次のNo と同じ順） |
| メモ | 補足（部品のメモに入る） |

- 取り込みは常に新しい図を作ります（今の図は変わりません）
- 開始と終了は、書かなければ自動で付きます。差し戻しのように前へ戻る線は、上を回る直角の線になります
- 表に間違いがあると、行番号付きで理由が出ます

### Claude Code に頼む

形が違う Excel や議事録からでも、ご自分の Claude Code に「この Excel を業務フローにして」と頼めば、上の表の形に整えてから取り込みます（手順は `.claude/skills/flowcanvas-import/SKILL.md`）。`ClaudeAgents` フォルダで `claude` を起動してください。Excel の中身は `npm run dump -- 資料.xlsx` で表示できます。

## PDF の書き出し

A3 で、図の形に合わせて横向き・縦向きを選びます。1ページに収めると文字が小さくなりすぎる大きな図は、横に分けて複数ページにします（2ページ目からも左端に枠の名前が付きます）。

## アプリのアイコン

ブラウザのタブに FlowCanvas のアイコンが出ます。Chrome や Edge では、アドレスバー右のインストールのマークか、メニューの「アプリとしてインストール」から、デスクトップにアイコン付きで置けます（`npm run dev` を起動しているときだけ開けます）。

## 構成

| 場所 | 中身 |
|---|---|
| `server/index.ts` | Express。保存API（`/api/flows`）と、ビルド後の画面の配信 |
| `src/model/` | データの型、サンプル、座標計算 |
| `src/store/` | 画面の状態、取り消し履歴（50件）、自動保存 |
| `src/components/` | ツールバー、左右のパネル、キャンバス |
| `src/export/` | 画像（PNG/JPG/PDF）とテキストの書き出し |
| `src/import/` | Excel・CSV の読み込みと、取り込み用ひな形（画面とコマンドで共通） |
| `mock/flowcanvas_mock.html` | 元になったモック（参照用） |
| `FlowCanvas_仕様書.md` | 仕様書 |
