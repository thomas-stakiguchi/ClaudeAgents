# FlowCanvas 全社展開案（検討メモ）

最終更新：2026-10-27　状態：**保留中**（あとで検討を再開する）

## いまの作り（事実）

- 各自の PC で `npm run dev` を実行して使う。図は `flowcanvas/data/` に JSON ファイルで保存される
- 保存は Node.js + Express のサーバー（127.0.0.1:3001）が担当。自分の PC からしか使えない
- 使い始めるのに Git・Node.js・コマンド操作が必要で、エンジニア以外には難しい

## 配り方の候補

| 案 | 内容 | 利用者の手間 | 図の共有 | 作る手間 | 運用の手間 |
|---|---|---|---|---|---|
| **A** | 画面だけを置いて URL で開く（サーバーなし） | ブラウザで開くだけ | ファイルでやり取り | 小 | 小 |
| B | 社内 Web サービス（ログイン・DB あり） | ブラウザで開くだけ | 画面内で共有・共同編集 | 大 | 大 |
| C | PC アプリを配る | インストールが必要 | ファイルでやり取り | 中 | 中 |
| D | 今のまま手順書を配る | 大 | なし | なし | 各自任せ |

おすすめは **まず A、共同編集が必要になったら B**。

## A案で決まっていること・わかっていること

- 置くもの：`npm run build` でできる `dist` フォルダ（HTML・JS・CSS・アイコン、数 MB）
- 先に必要な改修：図の保存先をサーバーからブラウザの中（IndexedDB など）に変える
- 図の控えは「保存」の後に出る「ファイルにも保存」で残す（実装済み・PR #12）
- **Google ドライブには置けない**（2016 年に Web ページ公開の機能が終わっている）
- 社内にサーバーはない（ユーザー談）

### サーバーなしで置ける場所

| 置き場所 | 社内の人だけに絞れるか | メモ |
|---|---|---|
| Google Apps Script | 自社ドメインの Google アカウントに限定できる | Google Workspace 利用が前提。画面が特別な枠の中で動くため、保存先フォルダ選択やブラウザ内保存が動くかは要検証 |
| Cloudflare Pages + Access | 会社のメールアドレスで限定できる | 無料枠あり（料金は要確認） |
| GitHub Pages | 無料プランでは誰でも見られる | 社外に見えても困らない場合のみ |
| 1つの HTML ファイルを配る | ― | Google ドライブで配布できるが、更新のたびに配り直し |

## 進んだこと

- 2026-10-27：**ファイルを配る方式**を実装。`npm run build:file` で `release/FlowCanvas.html` を作り、特定の人に共有して使う
  - ダブルクリックで開いた状態（file://）で、保存・開き直し・新しい図・削除・Excel 読み込み・PNG 書き出しが動くことを Chromium で確認
  - 保存先フォルダを選ぶ画面は、自動テストでは開けないため実機の Chrome・Edge で要確認
  - 更新のたびに配り直しが必要。URL で開く方式（Apps Script など）は引き続き保留

## 未確認・次に決めること

1. 会社で使っているのは Google Workspace か Microsoft 365 か
2. 公開範囲・置き場所について情シス／管理者の確認
3. 業務フローに社外秘の情報が入るか
4. 図は各自で作れれば十分か、部署で共有・共同編集までしたいか

## 再開したら最初にやること

- 上の 1〜4 をユーザーに確認する
- Google Workspace なら：保存先のブラウザ化と1ファイル化を試作し、Apps Script で動くかを検証する
